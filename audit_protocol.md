# Audit Protocol

## Purpose
Keep a brief record of how the team checks AI-assisted analysis. The log documents the team's actual checks; it is not a record of routine approvals.

## Checks to use
- **Source and schema:** Confirm the source, date coverage, table, field, unit, and definition before relying on them.
- **Query and calculation:** Compare the query logic and key calculations with the stated KPI definition; record what was checked and the result.
- **Interpretation:** Separate measured results from explanations or recommendations. Treat observational patterns as associations unless the design supports causal claims.
- **Model:** Confirm the target or clustering question, input fields, evaluation method, and limits before using a model result to recommend action.

## Logging
The agent proposes a concise entry in the relevant category. A team member reviews it and approves or corrects it before it is added to audit_log.md. Do not record a check that did not happen.

## Changes to this protocol
Propose additions when a meaningful review reveals a reusable practice. The team approves changes before they are applied.
